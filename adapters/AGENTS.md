# mmx instructions for harnesses without hooks

At the start of every turn, before editing the configured project diagram, run `mmx render diagram.mmd --by human --print-if-changed` (replace `diagram.mmd` with the actual path). Read a newly printed diff as the human's message. Immediately after each agent edit to a `.mmd` file, run `mmx render <edited-file>.mmd --by agent --note "what changed and why" --print-if-changed`. If mmx exits 2, read `<stem>.diff.json.error`, repair the parse or encoding problem yourself, and render again. A no-op writes and prints nothing. The note is stored only in diff.json for its next reader. When hooks are installed, notes for Edit/Write edits are not recorded: the hook renders first, so the agent's render with `--note` is a no-op. A command to add a note is planned for v1.
