# mmx instructions for harnesses without hooks

At the start of every turn, before editing the configured project diagram, run `mmx render diagram.mmd --by human --print-if-changed` (replace `diagram.mmd` with the actual path). Read a newly printed diff as the human's message. Immediately after each agent edit to a `.mmd` file, run `mmx render <edited-file>.mmd --by agent --note "what changed and why" --print-if-changed`. If mmx exits 2, read `<stem>.diff.json.error`, repair the parse or encoding problem yourself, and render again. A no-op writes and prints nothing. The note is stored in diff.json and `<stem>.turns.jsonl` and shown to the human by `mmx serve`. If the render was a no-op (a hook or `mmx serve` rendered first), or to reply without editing, run `mmx note diagram.mmd "message"` (always a turn, by agent; includes any unrendered edits).

After your turn, run `mmx wait diagram.mmd --timeout 300`. Exit 0: each printed line is the diff JSON of an unanswered human turn (oldest first); respond with an edit + `mmx render --by agent --note "..."` or with `mmx note`, then wait again. Exit 3: nothing yet; call again or stop. With `mmx serve` running, direct file edits are attributed to the agent; without serve, `mmx wait` renders direct file edits as the human's turns.
